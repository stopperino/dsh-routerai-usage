# dsh-routerai-usage

Баланс и стоимость запросов [RouterAI](https://routerai.ru) в веб-интерфейсе DeepSeek Harness.

Показывает баланс личного кабинета и то, что реально израсходовала текущая сессия — включая всех
субагентов, которых она породила, — под полем ввода, с панелью, где расход разложен по провайдеру
и по модели.

```
505,14 ₽   ◎ 147,04 ₽
```

Нажмите на цифру, чтобы раскрыть детализацию. Панель открывается **только по клику** — наведение
мыши её не раскрывает; закрывается повторным кликом, кликом вне панели или клавишей Escape.

```
◈ routerai                                    505,14 ₽
всего 147,04 ₽ · 848 запросов
в т.ч. субагенты: 33,35 ₽ · 222 запроса
По провайдеру
  byteplus                       822 запроса · 141,27 ₽
По модели
  deepseek-v4.1-flash            848 запросов · 147,04 ₽
```

## Почему стоимость точная

RouterAI выставляет счёт через маршрутизируемого провайдера, и цена там **не** совпадает с
публичным прайс-листом. Для `deepseek/deepseek-v4.1-flash` реальное списание замерено на
постоянном уровне **2,793×** от оценки по прайс-листу. Плагин, который умножает токены на
публичные цены, ошибается примерно в 3 раза — поэтому этот спрашивает у RouterAI фактическую
сумму:

```
GET https://routerai.ru/api/v1/generation?id=<generation-id>   →   data.total_cost   (рубли)
```

Идентификатор генерации берётся из самого журнала сессии Harness
(`assistant/message` → `message.source.replayState.response.responseId`), так что перехватывать
или воспроизводить запросы не нужно.

## Трафик

Каждое списание кэшируется по идентификатору генерации. Идентификатор обозначает один неизменный,
уже оплаченный запрос, поэтому его стоимость никогда не меняется и кэш не может устареть.
Повторное открытие уже закэшированной сессии стоит **ноль обращений к серверу** — замерено:
848 строк разрешились за ~12 мс против ~4 с и сотен запросов при холодном кэше.

Кэш хранит только пары `generationId → рубли`. Никаких токенов, моделей, промптов и содержимого
сессий. Запись атомарная; нечитаемый файл просто игнорируется.

`GET /credits` следует за тем, смотрит ли кто-то на виджет. Пока виджет смонтирован, клиент
опрашивает `/rows` каждые 1,5 с, и это же служит сигналом присутствия, так что баланс обновляется
раз в `pollSeconds`. Как только опрос прекращается, хост растягивает интервал до `idlePollSeconds`
(по умолчанию 5 минут), а клиент вообще перестаёт опрашивать при скрытой вкладке. Фоновый трафик
падает с 2 880 запросов в сутки до ~288, вместо того чтобы круглосуточно дёргать шлюз.

## Установка

Плагин ставится в профиль Harness. Подставьте имя своего профиля вместо `web`
(`dsh plugin --profile <имя> add …`); для десктопного приложения профиль обычно называется
`desktop`.

```bash
dsh plugin --profile web add https://codeload.github.com/stopperino/dsh-routerai-usage/tar.gz/refs/tags/v1.2.2
```

Эта ссылка — обычный tarball с GitHub, **Git на машине не нужен**. Именно поэтому она указана
вместо `github:stopperino/dsh-routerai-usage`: установка git-ссылки запускает `git ls-remote`,
поэтому на компьютере без Git (или без доступа к git-транспорту GitHub) она падает ещё до
скачивания пакета. Tarball-ссылка скачивается по HTTPS и работает на чистой машине.

Чтобы поставить последнюю версию из ветки `main`, а не тег:

```bash
dsh plugin --profile web add https://codeload.github.com/stopperino/dsh-routerai-usage/tar.gz/refs/heads/main
```

Плагин — это `dsh`-bundle: после установки он появляется в списке плагинов профиля и включается
там. Две вещи, без которых виджета не будет:

- в профиле должен быть веб-интерфейс Harness — bundle `@deepseek-ai/dsh-web-app`. Без него
  плагин устанавливается, но его хост-часть навсегда остаётся в состоянии
  `pending (waiting for service: webServer)`: маршрут `/api/dsh-routerai-usage` регистрировать
  некуда, а рисовать виджет негде. Профили `web` и десктопное приложение содержат этот bundle;
- нужен ключ `ROUTERAI_API_KEY` (см. ниже). Без него плагин работает, но показывает «нет ключа».

### Если установка не проходит

- `ERR_PNPM_GIT_RESOLVE_FAILED` / `spawn EPERM` — вы ставите `github:`-ссылку, а Git недоступен.
  Используйте tarball-ссылку из примера выше.
- `error: required option '--profile <name>' not specified` — пропущен `--profile`. У команды
  `dsh plugin` нет подкоманды `install`: аргументы после `--profile <имя>` передаются в `pnpm`,
  поэтому нужен именно `add <ссылка>`.
- `installation rejected: … incompatible with dsh …` — версия Harness старше `0.1.7-rc.1`.
  Обновите Harness либо выдайте исключение:
  `dsh plugin --profile web allow-version dsh-routerai-usage@1.2.2 --dsh-version <версия> --accept-risk`.
- `dsh: cannot resolve profile bundle "dsh-routerai-usage"` — пакет не попал в
  `node_modules` профиля; повторите `add` и проверьте, что профиль тот самый.

### Установка из локального каталога

Для разработки можно поставить каталог напрямую — но учтите, что в манифест профиля попадёт
**абсолютный** путь `link:…`, поэтому такой профиль не переносится на другую машину:

```bash
dsh plugin --profile web add /абсолютный/путь/к/dsh-routerai-usage
```

## Настройка

Строка принимает следующие параметры в `cordis.patch.yml`:

```yaml
- id: routerai-usage
  name: dsh-routerai-usage
  config:
    pollSeconds: 30                          # обновление баланса, пока виджет на экране
    idlePollSeconds: 300                     # обновление баланса, пока никто не смотрит
    baseURL: https://routerai.ru/api/v1      # корень API
```

Оба интервала снизу ограничены 10 секундами, и `idlePollSeconds` никогда не опускается ниже
`pollSeconds`.

## Ключ доступа

Ключ RouterAI читается через службу учётных данных Harness по имени `ROUTERAI_API_KEY` — тому же,
что использует провайдер модели `routerai`. Плагин нигде его не сохраняет, не пишет в журналы и не
возвращает в браузер. Если ключа нет, виджет показывает «нет ключа», а остальной Harness работает
как обычно.

## Что уходит с вашей машины

Ровно два вида запросов, оба к тому API RouterAI, который вы настроили:

| Запрос | Назначение |
|---|---|
| `GET /credits` | баланс личного кабинета |
| `GET /generation?id=…` | фактическая стоимость одного уже оплаченного запроса |

Ничего не отправляется автору плагина или третьим лицам, телеметрии нет.

## Совместимость

Требуется DeepSeek Harness `0.1.7-rc.1` или новее (`engines.dsh` в `package.json`). Собрано и
проверено на `0.2.1-rc.3`. Клиентская часть регистрируется в `conversation.composer.dock` и
использует только токены темы `--dsw-alias-*` (каждый с запасным значением), поэтому
переименованный токен ухудшает вид, но не ломает отрисовку. Хост-часть требует сервис
`webServer`, который предоставляет bundle `@deepseek-ai/dsh-web-app`; в профилях без веба
(например, `headless`/`acp`) плагин остаётся неактивным.
