# dsh-routerai-usage

Баланс и стоимость запросов [RouterAI](https://routerai.ru) в веб-интерфейсе DeepSeek Harness.

Показывает баланс личного кабинета и расход текущей сессии — включая субагентов — под полем
ввода. По клику раскрывается детализация: сколько ушло и на какого провайдера и модель.

```
505,14 ₽   ◎ 147,04 ₽
```

```
◈ routerai                                    505,14 ₽
всего 147,04 ₽ · 848 запросов
в т.ч. субагенты: 33,35 ₽ · 222 запроса
По провайдеру
  byteplus                       822 запроса · 141,27 ₽
По модели
  deepseek-v4.1-flash            848 запросов · 147,04 ₽
```

Панель открывается **только по клику** — наведение мыши её не раскрывает. Закрывается повторным
кликом, кликом вне панели или клавишей Escape.

## Установка

Подставьте имя своего профиля вместо `web`: у десктопного приложения это обычно `desktop`.

```bash
dsh plugin --profile web add https://codeload.github.com/stopperino/dsh-routerai-usage/tar.gz/refs/tags/v1.3.1
```

Это обычный tarball с GitHub, **Git на машине не нужен**. Ссылку `github:stopperino/dsh-routerai-usage`
лучше не использовать: она требует установленного Git и падает ещё до скачивания пакета, если его
нет. Tarball качается по HTTPS.

Последнюю версию из ветки `main` вместо тега:

```bash
dsh plugin --profile web add https://codeload.github.com/stopperino/dsh-routerai-usage/tar.gz/refs/heads/main
```

После установки плагин появится в списке плагинов профиля — включите его там. Ему нужен
веб-интерфейс Harness (bundle `@deepseek-ai/dsh-web-app`): в профилях без веба, например
`headless` или `acp`, плагин установится, но останется неактивным.

### Если не устанавливается

| Сообщение | Причина и что делать |
|---|---|
| `ERR_PNPM_GIT_RESOLVE_FAILED` / `spawn EPERM` | Ставите `github:`-ссылку, а Git недоступен. Возьмите tarball-ссылку выше. |
| `required option '--profile <name>' not specified` | Пропущен `--profile`. Подкоманды `install` у `dsh plugin` нет — нужен `add <ссылка>`. |
| `installation rejected: … incompatible with dsh …` | Harness старше `0.1.7-rc.1`. Обновите его либо выдайте исключение: `dsh plugin --profile web allow-version dsh-routerai-usage@1.3.1 --dsh-version <версия> --accept-risk`. |
| `cannot resolve profile bundle "dsh-routerai-usage"` | Пакет не попал в `node_modules` профиля. Повторите `add` и проверьте, что профиль тот самый. |

Для разработки можно поставить каталог напрямую, но в манифест профиля попадёт **абсолютный**
путь `link:…`, и такой профиль не переносится на другую машину:

```bash
dsh plugin --profile web add /абсолютный/путь/к/dsh-routerai-usage
```

## Пиковые часы

Некоторые провайдеры берут в часы нагрузки вдвое больше — у DeepSeek так. В это время цифра баланса
краснеет, а в панели первой строкой появляется предупреждение:

```
Пиковые часы: цена 2× · до 15:00 (местное)
```

Время местное, по вашему часовому поясу. В обычные часы виджет выглядит как раньше.

Расписание плагин берёт у RouterAI, а не из зашитого списка, поэтому модели, у которых провайдер
объявит такие окна, попадают в предупреждение сами. Сейчас окна есть у моделей DeepSeek; у GLM,
Kimi, Qwen, GPT, Claude, Gemini, Grok и MiniMax тариф плоский.

Расписание перечитывается раз в полчаса и только для моделей из вашей сессии. Ключ для этих
запросов не нужен. Если сети нет, предупреждение просто не появится — баланс и стоимость работают.
Отключается через `peak: false`.

## Почему стоимость точная

RouterAI маршрутизирует запрос к одному из провайдеров модели, и цена там не совпадает с публичным
прайс-листом: для `deepseek/deepseek-v4.1-flash` списание держится около **2,793×** от оценки по
прайсу. Плагин не умножает токены на цены, а спрашивает у RouterAI фактическую сумму:

```
GET https://routerai.ru/api/v1/generation?id=<generation-id>   →   data.total_cost   (рубли)
```

Идентификатор генерации берётся из журнала сессии Harness, так что перехватывать запросы не нужно.

## Настройка

```yaml
- id: routerai-usage
  name: dsh-routerai-usage
  config:
    pollSeconds: 30                          # обновление баланса, пока виджет на экране
    idlePollSeconds: 300                     # обновление баланса, пока никто не смотрит
    baseURL: https://routerai.ru/api/v1      # корень API
    peak: true                               # предупреждать о пиковом тарифе
    peakRefreshSeconds: 1800                 # как часто перечитывать расписание тарифов
```

Оба интервала снизу ограничены 10 секундами, и `idlePollSeconds` не опускается ниже `pollSeconds`.

## Ключ доступа

Ключ читается через службу учётных данных Harness по имени `ROUTERAI_API_KEY` — тому же, что
использует провайдер модели `routerai`. Плагин его нигде не сохраняет, не пишет в журналы и не
возвращает в браузер. Без ключа виджет показывает «нет ключа», остальной Harness работает как обычно.

## Что уходит с вашей машины

Только запросы к тому API RouterAI, который вы настроили:

| Запрос | Назначение |
|---|---|
| `GET /credits` | баланс личного кабинета |
| `GET /generation?id=…` | фактическая стоимость уже оплаченного запроса |
| `GET /models/{модель}/endpoints` | расписание пиковых тарифов (без ключа) |

Ничего не отправляется автору плагина или третьим лицам, телеметрии нет.

## Трафик

Стоимость каждого запроса кэшируется по идентификатору генерации: он обозначает один неизменный
оплаченный запрос, поэтому кэш не устаревает. Повторное открытие сессии не делает ни одного
обращения к серверу — замерено 848 строк за ~12 мс против ~4 с при холодном кэше.

Баланс обновляется, только пока виджет на экране: клиент опрашивает его каждые 1,5 с, и это же
служит сигналом присутствия. Когда опрос прекращается, интервал растягивается до `idlePollSeconds`,
а при скрытой вкладке опрос останавливается совсем. Фоновый трафик — около 288 запросов в сутки
вместо 2 880.

Кэш хранит только пары `generationId → рубли`: никаких токенов, моделей, промптов и содержимого
сессий.

## Совместимость

DeepSeek Harness `0.1.7-rc.1` или новее; собрано и проверено на `0.2.1-rc.3`. Клиентская часть
использует только токены темы `--dsw-alias-*` (каждый с запасным значением), поэтому
переименованный токен ухудшит вид, но не сломает отрисовку.
